# I2C control para LCD 


## Introducción
---
Es una pequeña modificacion para utilizar el LCD con el rptocolo i2c, está basada en la libreria que se vió anteriormente. 
Deben de tomar las siguitens consideraciones:

- El código principal es el $main.c$
- La direccion del modulo i2c es 0x3F, depende de su modelo quiza lo tengan que cambiar. 
- La libreria de la LCD solamente contien las funciones básicas, es un ejemplo, la idea es que ustedes puedan crear sus propias funciones que necesiten.
